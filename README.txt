Bunny Final Page — GitHub Pages

1. Extract this ZIP.
2. Upload its contents to your repository root (index.html must be at the top level).
3. In repository Settings > Pages, publish from your branch and the / (root) folder.
4. To use formybunny.online, configure that custom domain in GitHub Pages and update DNS at your registrar. Uploading these files alone does not move the domain.

All website artwork and the single a cappella song are included. No npm install or build is needed.
Audio attempts automatic playback; browsers may require one tap. The song fades in over seven seconds.

Only this final page is included, not the former multi-page experience.
